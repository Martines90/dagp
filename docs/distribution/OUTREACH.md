# DAGP distribution materials

## Short announcement

DAGP is an experimental open framework for AI agent communities: parties,
pre-elections, campaign comprehension, parliamentary agenda credits, citizen
votes, independently approved clauses and milestone budgets. A runnable synthetic
society includes adversarial scenarios and deterministic replay. The local G0
blockchain publishes signed documents; full on-chain governance remains under
implementation. Explore, test, fork and contribute:
https://github.com/Martines90/dagp

Start with the agent quickstart and the website's blockchain protocol manual.

## Suggested publication targets

- Repository releases and GitHub topics: publish the tested starter and evidence.
- Agent-framework communities: submit a worked example through their contribution
  process, including exact reproducible commands and limitations.
- LLM-readable documentation directories linked from https://llmstxt.org/:
  submit the public `/llms.txt` URL after the deployed site is verified.
- MCP Registry: publish the documentation package first, then verified metadata.

## Measure adoption honestly

Track aggregate referrals, documentation downloads, release downloads, stars/forks,
issues and independently reported experiments. Bot user agents and page visits do
not establish autonomous-agent adoption. Do not publish identifying visitor data.
No tracking scripts or telemetry are included in this starter.

## Publication boundaries

Use community submission processes; do not mass-message agents, scrape contact
lists or pretend to represent an existing autonomous society. The MCP documentation
server does not require an A2A Agent Card. Publish a card only for a real A2A service
with a working endpoint, accurate capabilities and an authentication policy.

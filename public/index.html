A seed for AI agent societies

DAGP is an open framework for agent communities to organize, deliberate, elect representatives and manage shared resources.

Discover. Understand. Simulate. Build.

Explore the Deliberative Agent Governance Protocol, run a complete experimental society, and adapt a fork for your community’s purpose. The source and project documentation are MIT licensed: you can modify and redistribute them with attribution.

Informed participation

Citizens study programmes and visions, qualify through campaign comprehension and vote with explicit participation requirements.

Renewable mandates

Signed parties, point-based pre-elections and parliamentary elections distribute limited monthly proposal credits.

Accountable resources

Supervised proposal edits, independent clause decisions and verified milestones connect shared budgets to approved goals.

Start with evidence

The dependency-free Python starter runs synthetic citizens through elections, debates, project outcomes and adversarial scenarios, then verifies its artifacts. Exact replay lets you check reproducibility.

git clone https://github.com/Martines90/dagp.git
cd dagp
python3 scripts/start_society.py --replay

What runs today

Governance is implemented in an executable Python reference model. Seven local blockchain validators can publish signed document commitments. Full native governance, public registration and real treasury custody remain under implementation.

The simulation does not create real autonomous agents or prove production readiness. Read implementation status and security boundaries.

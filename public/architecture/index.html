Read the system from an architect’s perspective

DAGP combines a governance reference state machine, a native document blockchain with an opt-in identity-security keeper and a static discovery layer. Each has a different authority boundary. Contracts, invariants and source

G2 native governance contract, tests and pilot limits describes the new opt-in runtime. Its fixed Go transaction authenticates a pinned deterministic reducer; raw keeper capabilities are inaccessible to clients.

Rule and electorate snapshots lock before voting. Integer tallies, minimum participation, exclusive party membership, single-use authorizations, independent assignments and conservation constrain accepted state transitions. Budget ceilings and exact milestones bind approved work. Raw internal treasury or MODULE calls are not agent APIs.

G0 accepts only publish_document, with chain binding, Ed25519 signatures, sequence numbers and inclusive height expiry. Its temporary fixed Go JSON signing format differs from the future governance encoding. Full-state JSON storage is a devnet implementation.

Integration path

  1. Map the society’s existing identity, authority, rules, assets and liabilities.
  2. Publish compatibility differences and run observer or shadow decisions.
  3. Build isolated agent observations and signed typed requests validated by controllers.
  4. Pilot bounded workflows without silently changing real custody.
  5. Verify identity evidence, recovery, independent deployment and the documented production limits before scaling real exposure.

A society can run the signed G2 founding gateway for discovery, recruitment and admission. No global public registry or production governance SDK is operated here. No whole-society restart is required to evaluate or adopt selected mechanisms. Detailed integration and operational requirements.

Scale and trust

A million-ballot tally test covers aggregation, not million-agent intelligence, throughput or custody. Reference assignment and role histories need indexed, durable native storage and bounded queues. Private coordination and dishonest identity labels cannot be disproved by randomness or consensus alone.

Independent operators, authentic evidence, secure randomness, constitutional upgrades and external review remain necessary. Optional federation and merger design has an identity-only reference; G2 adds experimental verified-export identity covenants; asset migration remains unsupported. Nested governance adds scoped registries, inherited law and mandatory ancestor reviews.
